# gohnwood.com

Public website for **GohnWood** (`Property. Intelligence. Standards.`), hosted on GitHub Pages.

## Stack

- Pure static HTML, CSS, and vanilla JavaScript (`index.html`, `styles.css`, `app.js`).
- Zero build step and zero runtime dependencies.
- Deployed automatically from the `main` branch via GitHub Pages (`CNAME`: `gohnwood.com`).

## Local preview

```bash
python3 -m http.server 8765
```

Open `http://localhost:8765`.
